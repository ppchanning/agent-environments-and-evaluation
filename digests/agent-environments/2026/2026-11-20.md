## Mirror Dimension for Agents: Evaluating Browser-Use Agents Without the Web

[原始来源](https://blog.google/security/mirror-dimension-for-agents/) · 2026-11-19 · official_technical_article

隔离Chrome通过本地代理访问合成网站，保留熟悉网址。研究、构建和审查agent依用户旅程生成交互，借助DevTools检查购物车持久化、结账、表单边界和控制台错误，再迭代返修。每条轨迹恢复干净基线；测试选择信息从可见URL转入过滤请求头，减少测试线索。

证据边界：官方工程文章的每日每工程师千余测试候选是生成吞吐，不是网站正确率或攻击成功率；没有与生产服务配对的状态转移保真测量。

建议先读：Spinning a Synthetic Web、Stealthy Payload Injections。

## Agentic World Modeling for Agent Test-time Scaling without Environment Replica

[原始来源](https://arxiv.org/abs/2610.40927) · 2026-10-29 · preprint

AWM在预测假想动作后观察前，自适应调用真实基础环境的只读接口取证；假想动作后果保留在轨迹历史，基础状态不变。隔离子agent返回紧凑观察，可借受限Python精确构造长字符串。τ-bench、AppWorld和OfficeBench中的候选选择实验支持在线取证及程序化观察构造的效用。

证据边界：预测时持续访问基础环境，不是构建后脱离参考系统的离线副本。相同候选数不等于相同成本；下游任务成功不等于逐状态转移精确匹配。摘要百分比与正文百分点口径不同，不转述总平均增益。

建议先读：§3.1–3.2、表1、图2–3。

## From the Wild Web to the Zoo: A Realistic Environment for Evaluating Web Agents

[原始来源](https://research.mozilla.org/files/2026/06/from_the_wild_web_to_the_zoo.pdf) · 2026-02-27 · conference_work_in_progress

ZOO部署互通的邮件、商城、代码托管、协作和身份应用，内部代理及隔离网络阻断外网，真实后端处理跨应用交互。数据库与配置从黄金副本恢复，缓存关闭持久化；宿主端可检查实际状态。它为可重置、可检查的参考环境提供工程实例。

证据边界：MADWeb work-in-progress主要提供实现与单个Browser Use/GPT-4o-mini简化攻击演示，不支持一般攻击成功率；未测与生产服务逐条配对的重建精度。真实应用部署不是自动生成模拟器。

建议先读：§III.C、§IV.C。
