## 1. CAREFUL-Bench: Effect-Aware, Judge-Free Evaluation of Multi-Turn LLM Function Calling

[原始来源](https://arxiv.org/abs/2611.02978) · 2026-11-02 · v2, 2026-11-03

用800条参考轨迹、128个函数与确定性回放评估状态效果；效果标注仍含两名人类及两个语言模型。可支撑模拟器的状态效果验证，采样效果不等于穷尽行为。

**证据：** 800 reference trajectories,128 functions; deterministic replay scoring; effect annotations include two humans and two LMs

**限制：** Sampled state effects; own BFCL simulators; abstract/HTML rho and maximum-drop discrepancy excluded from report

**先读：** §4–5与表3

## 2. Unfinished-Bench: Measuring Rule Violations by Persistent Agents in Realistic Work Environments

[原始来源](https://arxiv.org/abs/2611.17460) · 2026-11-12 · v1

97场景各两种变体，12模型各1164次运行，使用代码审计和状态违规判分。持久性组合三种干预，每组合一次运行；评估规则遵循，不是模拟器重建保真评测。

**证据：** 97 scenarios x2 variants;12 models x1164 runs; code-based audit/state violation scoring

**限制：** Persistence bundles three interventions; one run per combination; no simulator reconstruction fidelity evaluation

**先读：** §2.5–2.6与§4.1–4.4

## 3. GPT-6.2 System Card — Deployment Simulation of Internal Codex Traffic
