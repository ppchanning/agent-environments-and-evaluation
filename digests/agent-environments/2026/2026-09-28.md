# Agent Environment Reading · 2026-09-28

AI 辅助整理的公开资料阅读笔记。数字与结论归属于所引作者；未独立复现实验，也不代表维护者已逐篇阅读。历史核验信息见书目。

## 1. 优先读：VHD-Play——用已解机制约束生成环境

**Verifiable Hidden Dynamics Play: Generating Agentic RL Environments from Solved Mechanisms**
Xinjie Shen等，Georgia Tech / Alibaba Token Foundry；首发与所核v1：2026-09-23。**近7天新推荐**。[摘要与日期](https://arxiv.org/abs/2609.27321) · [原始正文](https://arxiv.org/html/2609.27321v1)

**方法与作者证据：**先求解参数化机制，再生成状态化工具与环境，以预先计算的结果校验执行。附录B对8个支持回放的机制族各抽10个环境，用oracle/default/idle策略重复执行，共480次；作者报告无异常且重复终态收益一致。表2将完整题面、参数公开的交互、需要获取参数的交互分开，提供了信息难度与交互难度的对照。

**局限：**这是已知机制的实现校验，并非未知服务规则的恢复；有限参考策略通过，不等于任意动作序列等价。部分机制使用事后上界，不能一概当在线可达最优值。训练收益也不能单独归因于校验器。

**先读：**附录B → §5.2表2 → 附录K。元数据缺口：摘要页与HTML作者列表不完全一致，当前仅使用“Xinjie Shen等”，完整书目信息待核。

## 2. 近30天补读：Terminal-Universe——轨迹可以重建什么

**Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments**
Jie Wu等，Qwen/Alibaba与清华团队；首发与所核v1：2026-09-03。[摘要与日期](https://arxiv.org/abs/2609.04148) · [原始正文](https://arxiv.org/html/2609.04148v1)

**方法与作者证据：**从交互轨迹回放出行动前的文件状态，再补全遗漏的任务资源并筛选。表2中Terminal环境的任务充分性判定从40.2%提高到93.5%。论文同时说明未访问文件、依赖和外部网络使恢复有损；原文包含污染过滤与仓库去重，不能说它完全未控制污染。

**局限：**任务充分性是围绕原任务的判定，不等于原环境的行为等价。补全可能产生可解决任务的新环境，仍不保证陌生请求下符合真实服务规则；代码终端结果也不直接证明API仿真有效。

**先读：**§3.1重建 → §3.3筛选 → §4.2与表2；潜在产物是轨迹缺失信息分类表。本轮不启动实现或实验。

## 3. 近30天补读：ReVeal——把保真度接到评测可靠性

**ReVeal: A Reconstruction-Aware Real-to-Sim Framework for VLA Policy Evaluation**
Xinyi Wang等，Purdue / Samsung SDS Research America；首发与所核v1：2026-09-20。首发北京时间9月21日06:36，早于首次窗口起点，故列30天补读。[摘要与日期](https://arxiv.org/abs/2609.23910) · [原始正文](https://arxiv.org/html/2609.23910v1)

**方法与作者证据：**比较3种场景重建流程，用同一策略检查点在真实与模拟环境上评测；8项机器人任务、3种策略，每个任务—策略条件各50回合。§V-C同时报告成功率相关性、排序违反MMRV与绝对误差MAE；表II中PGSR-D的MAE为0.050，2DGS为0.246。

**局限：**研究的是机器人场景重建，不能把视觉几何指标直接搬到服务API。所示保真度与可靠性的关联不是因果证明；对象重建和物理差异仍是作者列出的后续范围。

**先读：**§V-A/B配对控制 → §V-C与表II/III → 结论局限；潜在产物为“环境指标—下游指标”对照表。
