## 1. From Traces to Agentic Worlds: Agentic Language World Models for Interactive Environment Simulation

**主阅读候选｜last_7_days_supplement**。首发2026-10-05；核查v1（2026-10-05）。作者版/预印本；作者：Quanyu Long; Xiao Chen; Jianda Chen; Haozhen Zhang; Qisheng Hu; Jianzhu Bao; Wenya Wang。团队：作者名单已核；团队不作未核归属。

[原始摘要](https://arxiv.org/abs/2610.06100) · [本次正文版本](https://arxiv.org/html/2610.06100v1)

**方法与作者报告的证据：** 历史轨迹重建 worldbook；运行时维护持久状态，先提出状态效果，再由 harness 验证并提交。7类环境测单步；另2类文本环境测多轮。Table 2 的 ALFWorld 真实环境成功率93%，直接提示/Trace2Env在模拟内成功97%/88%，将模拟产生的动作重放到真实环境后仅3%/85%；CR=W2R/Real，分别0.032/0.914。

**局限与未证明之处：** 多轮结果只来自ALFWorld和SciWorld，不能外推全部9环境或生产API。单步主要用LLM裁判；W2R是任务成功率，不是逐步或最终状态严格等价率。轨迹、worldbook与运行时调用也须纳入信息和成本预算。

**先读：** §5.3 Table 2 → §4.2–4.3 → 附录A/B.3/C.3。

**可检验问题：** W2R成功的序列中，是否仍存在中间状态分歧或被任务终点掩盖的副作用？

## 2. BackendForge: Benchmarking Agentic End-to-End Code Generation with Backend Services

**主阅读候选｜older_important_supplement**。首发2026-07-13；核查v1（2026-07-13）。作者版/预印本；作者：Yuzhe Guo; Mengzhou Wu; Yuan Cao; Jialei Wei; Dezhi Ran; Wei Yang; Tao Xie。团队：作者名单已核；不据搜索目录推断团队。

[原始摘要](https://arxiv.org/abs/2607.11042) · [本次正文版本](https://arxiv.org/html/2607.11042v1)

**方法与作者报告的证据：** 56个spec/OpenAPI定义的服务任务，生成Docker服务后仅通过HTTP测试评分。测试agent提出新测试，review要求可追溯到契约，code agent仅修参考实现并全套回归。最终oracle含7,250基础项和640新增项；作者报告GPT-5.5全任务通过率由55.4%降至28.6%。

**局限与未证明之处：** 完整可见契约不同于黑盒行为发现。增强oracle同时覆盖多类问题，差值不能归因于某一种序列错误；测试与参考实现共同演化，仍需警惕共享遗漏。

**先读：** §3.4 → §4.2 → §5.1–5.3。

**可检验问题：** 当服务文档未规定失败行为时，应按真实服务观测、允许行为集合还是待定项评分？

## 3. Does Learning to Predict the World Help Agents Act? Auditing World-Model Post-Training

**主阅读候选｜last_30_days_supplement**。首发2026-09-27；核查v1（2026-09-27）。作者版/预印本；作者：Xinyu Che; Hang Yan; Yanchen Liu; Haochen Liu; Ruifeng Li; Anran Shi; Heng Wang; Jun Liu。团队：西安交通大学、USC、UCAS、华东师范大学；按正文署名。

[原始摘要](https://arxiv.org/abs/2609.33335) · [本次正文版本](https://arxiv.org/html/2609.33335v1)

**方法与作者报告的证据：** 比较正确下一观测GT、分布内错配MIS和独立随机奖励COIN。ALFWorld有候选动作设置下GT/MIS预测准确率57.00%/27.25%，下降29.75个百分点；pass@1为37.30%/34.55%，pass@64为83.94%/83.21%。预测质量大变，64次尝试覆盖却接近。

**局限与未证明之处：** 审计的是agent后训练效应，不是固定agent的服务副本保真。正确目标仍提高单次成功；不能据此说准确性无用。多次采样与单次部署含义不同，预测评估也依赖裁判。

**先读：** §2.2–2.3 → §3.1 Table 2 → §3.2–3.3。

**可检验问题：** 固定agent、尝试数与初态后，收益来自环境内容、动作候选约束还是探索分布变化？

## 4. Long-Horizon Textual World Modeling through Structured Reasoning

**备选｜last_7_days_supplement**。首发2026-10-05；核查v1（2026-10-05）。作者版/预印本；作者：Fangxin Wang; Xiang Gao; Yuguang Yao; Kaiwen Dong; Nikash Walia; Kamalika Das。团队：Intuit AI Research、University of Illinois Chicago；正文署名。

[原始摘要](https://arxiv.org/abs/2610.06637) · [本次正文版本](https://arxiv.org/html/2610.06637v1)

**方法与作者报告的证据：** 把整段未来动作变成一次解码中的稀疏状态编辑，以确定性Apply重建中间状态；蒸馏、预测增益和中间奖励训练。ScienceWorld、Jericho、CEO-Bench对照递推与直接预测。§5.4固定动作注入虚假状态事实，平均SE-score损失递推11.1、蒸馏SR5.4、完整SR1.7；后两者说明训练也影响结果。

**局限与未证明之处：** 文本模拟环境预测，不是可交互真实服务副本；完整方法同时改变训练及表示，须看匹配消融。作者明确闭环规划收益仍未解决；状态可机械重建不保证真实服务状态正确。

**先读：** §3.2与§4.1 → §5.3–5.5 → 附录E.2/E.3。

**可检验问题：** 同一初态切换不同未来动作，副本是否真正跟随动作分支，而非只预测常见终点？

## 5. Agent World Model: Infinity Synthetic Environments for Agentic Reinforcement Learning

**备选｜older_important_supplement**。首发2026-02-10；核查v3（2026-05-22）。作者版/预印本；作者：Zhaoyang Wang; Canwen Xu; Boyi Liu; Yite Wang; Siwei Han; Zhewei Yao; Huaxiu Yao; Yuxiong He。团队：Snowflake、UNC Chapel Hill；正文署名。

[原始摘要](https://arxiv.org/abs/2602.10090) · [本次正文版本](https://arxiv.org/html/2602.10090v3)

**方法与作者报告的证据：** 生成1,000个场景：任务→数据库schema/样例→代码工具环境，并读取数据库设计奖励。Table 6对100环境用GPT-5.1/Claude-4.5裁判：AWM含bug环境比例74%/83%，阻断任务比例14.0%/11.5%；运行可靠性不能从代码可执行直接推定。

**局限与未证明之处：** 上述bug比例是LLM裁判分析，非全部独立机械验证；作者另报告人工错误分类。训练跨基准泛化不证明固定真实服务行为等价。arXiv备注ICML2026接收；本次核的是v3作者版，未核正式出版关联及版本差异，不算更新。

**先读：** §3生成与奖励 → §6.1 Table 6 → §5.2泛化。

**可检验问题：** 机械状态检查能否发现任务可完成但失败调用留下错误副作用的环境？
