## 1. MCP-Persona: Benchmarking LLM Agents on Real-World Personal Applications via Environment Simulation

旧文补读；arXiv作者版（预印本来源）。首发2026-06-01，核查v1（2026-06-01）；不宣称版本更新。作者名单已核；arXiv备注ICML 2026 Camera Ready，正式出版关联未核。

作者：Wenhao Wang; Peizhi Niu; Gongyi Zou; Xiyuan Yang; Jingxing Wang; Haoting Shi; Yaxin Du; Jingyi Chai; Xianghe Pang; Shuo Tang; Yanfeng Wang; Siheng Chen。

[原始摘要](https://arxiv.org/abs/2606.02470)｜[本次核查正文](https://arxiv.org/html/2606.02470v1)

方法与作者报告的证据：从真实成功调用及对抗失败调用生成有状态Python仿真器，拆分持久上下文与工具内核。§4.3以Lark 14工具的50条真实调用评估；作者报告ToolTraverse准确率94%，仅文档版本58%。

局限：评估通过LLM裁判，且为每条调用逆向重建并注入前置上下文；单服务小样本不能证明未见序列或失败副作用等价，也未证明盲探测预算公平。

先读：§3.1 → §4.3/Table 4 → 附录A.2/B.3

可检验问题：失败创建后再查询，副本是否与固定参考保持相同状态？

## 2. BaxBench: Can LLMs Generate Correct and Secure Backends?

旧文补读；arXiv作者版（预印本来源）。首发2025-02-17，核查v3（2025-05-30）；不宣称版本更新。ETH Zurich、LogicStar、UC Berkeley、INSAIT；正文署名。

作者：Mark Vero; Niels Mündler; Victor Chibotaru; Veselin Raychev; Maximilian Baader; Nikola Jovanović; Jingxuan He; Martin Vechev。

[原始摘要](https://arxiv.org/abs/2502.11844)｜[本次核查正文](https://arxiv.org/html/2502.11844v3)

方法与作者报告的证据：由OpenAPI与文字规范生成可运行后端；28场景×14框架构成392任务。容器经HTTP接受框架无关功能测试，另有安全测试；参考正确实现经人工复核以检查测试。

先读：§2.1–2.2 → 附录B/D.1

可检验问题：文档未规定冲突与默认值时，评分依据是规范还是固定实现？

## 3. EnvScaler: Scaling Tool-Interactive Environments for LLM Agent via Programmatic Synthesis

旧文补读；arXiv作者版（预印本来源）。首发2026-01-09，核查v2（2026-04-17）；不宣称版本更新。中国人民大学高瓴人工智能学院/RUC-NLPIR；正文署名。

作者：Xiaoshuai Song; Haofei Chang; Guanting Dong; Yutao Zhu; Ji-Rong Wen; Zhicheng Dou。

[原始摘要](https://arxiv.org/abs/2601.05808)｜[本次核查正文](https://arxiv.org/html/2601.05808v2)

方法与作者报告的证据：主题→规则/状态→Python环境；前端代理提正负调用，后端代理检查代码、返回及状态变化。每环境100轮、质量阈值0.85；共191环境约7K场景，任务由末态布尔函数评分。

局限：质量门槛包含LLM判断，环境与验证器同源生成可能共犯错误。训练收益不能替代固定外部服务的配对忠实度；本次未核版本差异，不标实质更新。

先读：§3.2–3.4 → §4.2 → §5.7

可检验问题：生成器与验证器共享错误规则时，什么独立证据能检出？

## 4. Simulating Environments with Reasoning Models for Agent Training

旧文补读；arXiv作者版（预印本来源）。首发2025-11-03，核查v1（2025-11-03）；不宣称版本更新。Microsoft、University of Washington、Carnegie Mellon；正文署名。

作者：Yuetai Li; Huseyin A Inan; Xiang Yue; Wei-Ning Chen; Lukas Wutschitz; Janardhan Kulkarni; Radha Poovendran; Robert Sim; Saravan Rajmohan。

[原始摘要](https://arxiv.org/abs/2511.01824)｜[本次核查正文](https://arxiv.org/html/2511.01824v1)

方法与作者报告的证据：Simia以工具schema、历史和少量种子轨迹提示推理模型生成反馈；合成轨迹过滤JSON与已知工具错误，另以模拟反馈和奖励支持训练。作者报告训练后下游任务收益。

局限：语法/工具校验未保证语义正确；未接触实际testbed的模拟器可能合理地虚构实体。训练效用不能推出对指定服务的状态等价。

先读：§2.1–2.3 → 附录D/E

可检验问题：资料不足时，模型输出是在复现目标，还是补全一个自洽虚构服务？

## 5. GTM: Simulating the World of Tools for AI Agents

旧文补读；arXiv作者版（预印本来源）。首发2025-12-04，核查v2（2025-12-05）；不宣称版本更新。按arXiv列出的7名作者保存；页面人数描述不一致，机构未核不作归属。

作者：Zhenzhen Ren; Xinpeng Zhang; Zhenxing Qian; Yan Gao; Yu Shi; Shuxin Zheng; Jiyan He。

[原始摘要](https://arxiv.org/abs/2512.04535)｜[本次核查正文](https://arxiv.org/html/2512.04535v2)

方法与作者报告的证据：1.5B通用工具模型，以CARG合成20K工具/300领域数据，覆盖单轮、多轮和四类参数错误。Table 1借Qwen2.5-72B裁判报告三类综合平均89.4%。

局限：89.4%是LLM判断的综合值，非真实服务执行等价率；多轮一致性不保证持久状态正确。速度对照的设备/接口条件不同，不能泛化成本优势。

先读：§4.2 → §5.1/Table 1

可检验问题：错误响应看似合理时，是否遗漏了错误操作的真实副作用？
