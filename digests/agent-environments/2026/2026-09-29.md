# Agent Environments & Evaluation · 2026-09-29

AI 辅助整理的公开资料阅读笔记。数字与结论归属于所引作者；未独立复现实验，也不代表维护者已逐篇阅读。历史核验信息见书目。

## 1．优先：可执行参考答案的独立性

**Skill-based Agentic Evaluation for Real-time Data Science Tasks** — Aniruddha Tamhane等，Adobe；预印本，首发/v1 2026-09-15。**近30天补读**。[原始摘要](https://arxiv.org/abs/2609.16487) · [PDF全文](https://arxiv.org/pdf/2609.16487)

- **方法与作者证据：**面对动态数据，用可执行函数即时重算参考答案，再把输出拆为原子事实评分。实验用复现生产关系的合成数据库，55例中53例可比较通过/失败；相对自然语言参考，MCC从0.331到0.427。作者所谓29%是相对增幅，不是29个百分点。
- **局限：**参考函数仍需专家保证正确；被测技能与裁判同用Claude Sonnet 4.6，小规模合成数据不证明跨模型、跨系统有效。可执行参考不意味着整个裁判已机械化。

## 2．过程标签能暴露最终结果掩盖的错误

**OSWorld-Pro: Process-based Evaluation for Computer Use Agents** — Zhilin Wang等，NVIDIA；预印本，首发/v1 2026-09-21 16:55 UTC，即北京时间9月22日00:55。距本轮开始超过7天，故为**近30天补读**。[原始摘要](https://arxiv.org/abs/2609.24890) · [全文](https://arxiv.org/html/2609.24890v1)

- **方法与作者证据：**305项GUI任务、2814个渐进子目标、67264个人工步骤标签；按targeted、feasible、progress、completion检查过程。Table 1中一个模型的feasible宏F1仅61.9，人类为91.6，提醒不能用总分掩盖局部裁判误差。
- **局限：**这是GUI任务过程评测，不是服务机制重建或未见API组合泛化；与其他基准的分数差还混入任务分布变化，不能当作评测方式的纯因果效应。
- **先读：**§2、§4.2 Table 1、Appendix D.6。可复用产物：四类过程标签与服务状态断言的映射行。**检验问题：**非法写入随后被恢复、终态正确的序列，应在哪里判失真？

## 3．工业需求与新颖性边界

**How to Evaluate AI Agents From Tool Calls to Task Completion** — Sophia Abbassi、Chris Alexiuk、Davide Onofrio、Gomathy Venkata Krishnan，NVIDIA官方技术文章；2026-09-21，无可核版本历史。**近30天补读**。[原文](https://developer.nvidia.com/blog/how-to-evaluate-ai-agents-from-tool-calls-to-task-completion/)

- **作者主张与材料：**把有状态环境上的逐步有效性/用途和最终状态验真分层；配套成功率、跨次一致性、参数准确率、每成功任务成本。正文用SWE-bench轨迹说明，属于方法建议，不是仿真保真度对照实验；未采用页面自动摘要或营销性能主张。
- **局限：**没有证明自动重建的服务可替代参考环境，也没有检验未见序列。文章对其他基准的概括不能直接视为完整能力边界。
- **先读：**From scoring calls to scoring the environment、How to read an evaluation及Table 1。可复用产物：指标词典一行。**检验问题：**终态相同而中间失败副作用不同，是否会改变后续agent决策？
