# Editorial Policy

## Research scope

正式名称为 **Agent Simulation Environments（Agent 仿真环境）**。核心关注仿真环境的构建、生成与可信验证：有状态软件模拟器、工具服务仿真、浏览器与终端任务环境、轨迹驱动仿真、语言世界模型及合成训练环境。工具协议、状态测试和执行评测作为理解与验证仿真的支撑方向。

新增资料说明它与仿真的关系：被模拟的系统、状态与交互机制、环境生成方法、行为保真或执行验证。仅涉及通用 Agent 能力的资料需解释具体的仿真或验证关联。明确区分提出模拟器的工作与可借鉴的接口、测试、评测方法；不得为了主题定位把真实执行写成仿真。

## Evidence and authorship

本仓库由 AI 辅助整理。推荐不代表维护者实际读完，作者报告的数字不代表独立复现。预印本、正式论文、新闻报道与官方技术案例明确区分。优先链接作者、机构或项目原始页面，保留首发日期、版本和历史核验；版本更新不自动计作新论文。未知信息明确为未知，历史核验不保证今日仍有效。

数字保留分母、实验对象与限定条件。不同基准成绩不能直接作同条件比较。模拟器、真实软件和物理实验分别说明。

## Publication boundaries

只提交公开来源的元数据、事实目录、原创摘要和阅读建议。不要提交网页正文、PDF、第三方摘要全文、个人阅读反馈、聊天记录、未公开研究计划、凭据、绝对本地路径或运行日志。

## Updates

按资料日期归档，以 DOI、去版本 arXiv ID 或规范 URL 去重。正文、日期与主题索引一起更新，检查相对链接。只提交实质内容变化，不做空提交、倒签日期或只改时间戳。收到明确授权才可改变仓库可见性。

更新记录使用实际发布日；2026-10-10 补入的历史时间线明确按资料日期回溯，不代表更早的 GitHub 发布。区分当期条目数、新增去重条目数与修订数，数字应可由目录或实质变更核对。首页日常信息最多保留最近 7 个自然日，完整历史保存在中英文 CHANGELOG，重要更新单独保留。
