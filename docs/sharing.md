# Sharing Guide

分享名称：**Agent Simulation Environments（Agent 仿真环境）**。一句话介绍：围绕 Agent 仿真环境的构建、生成与可信验证，整理有状态模拟器、工具服务仿真、世界模型和执行验证的论文及技术资料。

永久入口：https://github.com/ppchanning/agent-environments-and-evaluation

分享单条资料时链接其归档页；科研结论引用原论文，集合结构可使用 [CITATION.cff](../CITATION.cff)。封面源文件：[banner.svg](../assets/banner.svg)。

本仓库公开供阅读与复用。每日归档只更新符合 [编辑标准](editorial-policy.md) 的材料；仓库可见性由维护者管理，归档任务不会自行更改。设计参考见 [Design References](design-references.md)。
