# Agent Simulation Environments

> Practical guides to selecting, generating and validating stateful simulation environments for AI agents.

Researchers and agents designing simulated task worlds, tool services and verifiable state transitions.

Start with three core guides, follow their primary sources, and reuse the JSON records. Pages are readable without login or JavaScript.

## Three core guides

| Question | What you get |
| --- | --- |
| [How to choose an agent simulation environment](guides/simulation-environment-selection.html) | Compare stateful simulators, mirrored tools, generated environments and learned worlds by the behavior a task needs. |
| [How to generate verifiable agent simulation environments](guides/environment-generation.html) | A design workflow from task specification to executable state, reset, verifiers and held-out validation. |
| [How to validate state and behavioral fidelity in agent simulators](guides/simulation-fidelity.html) | A practical test matrix for transitions, side effects, counterfactual traces, task success and transfer claims. |

## How to interpret the evidence

Guides distinguish primary-source descriptions, author-reported results and collection advice. Example templates are not measured results. Unknown access conditions do not imply free or permitted access. Cite the original paper for a scientific claim and this guide for its selection or curation method. Core guides and the Agent index have complete English and Chinese versions; most existing archive notes remain in Chinese.
